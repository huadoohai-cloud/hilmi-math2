Transformasi Geometri

Belajar translasi, refleksi, rotasi, dan dilatasi dengan ringkasan rumus, kalkulator titik, dan kuis latihan.

Empat transformasi utama

➡️

1. Translasi

Memindahkan titik sejauh tertentu tanpa mengubah bentuk, ukuran, atau arah.

(x, y) → (x + a, y + b)

Contoh: A(2, 3) ditranslasi T(4, −1) menjadi A′(6, 2).

🪞

2. Refleksi

Pencerminan titik terhadap garis tertentu.

Sumbu X: (x, y) → (x, −y)
Sumbu Y: (x, y) → (−x, y)
Titik O: (x, y) → (−x, −y)
Garis y = x: (x, y) → (y, x)
🔄

3. Rotasi

Memutar titik terhadap pusat rotasi. Untuk pusat O(0,0):

90° berlawanan jarum jam: (x,y) → (−y,x)
180°: (x,y) → (−x,−y)
270° berlawanan jarum jam: (x,y) → (y,−x)

Rotasi searah jarum jam 90° sama dengan rotasi 270° berlawanan arah.

🔍

4. Dilatasi

Memperbesar atau memperkecil dari pusat O(0,0) dengan faktor skala k.

(x, y) → (kx, ky)

Contoh: B(−2, 3), k = 2 → B′(−4, 6).

Jika |k| > 1 membesar; jika 0 < |k| < 1 mengecil.

Tips mengingat

• Translasi: tambah atau kurangi koordinat. • Refleksi: koordinat berubah tanda sesuai garis cermin. • Rotasi: posisi x dan y dapat bertukar. • Dilatasi: kalikan koordinat dengan faktor skala.

Catatan: rumus rotasi dan dilatasi di atas menggunakan pusat O(0,0), kecuali dinyatakan lain.

Kalkulator transformasi titik

Masukkan titik awal P(x, y), lalu pilih transformasi untuk melihat koordinat bayangannya.

P(2, 3) → P′(6, 2)

Kuis latihan

Jawab 8 soal untuk menguji pemahamanmu. Pilih satu jawaban pada setiap soal.

Skor: 0 / 8
